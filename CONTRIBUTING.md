# Участие в разработке

Для ошибки укажите версию приложения и Windows, число мониторов, масштаб каждого экрана и последовательность действий. Не прикладывайте личные заметки или содержимое буфера обмена; используйте демонстрационные данные.

Перед изменениями ознакомьтесь с README. Сборка выполняется через `source/build.ps1`, проверки — через `source/test.ps1` на Windows с MinGW-w64. Для изменений интерфейса проверьте светлую и тёмную темы, а для размещения — несколько мониторов и разный DPI.

В pull request опишите проблему, итоговое поведение и проведённые проверки. Не добавляйте пользовательские данные, исполняемые файлы или тестовые временные папки в исходники.
