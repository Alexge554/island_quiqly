# Island 2.1 — Компактная капсула

Нативное приложение для Windows 10/11 x64 на C++17 / Win32: последние 5 изображений из буфера Windows, короткие заметки, громкость и таймер. Без установщика, браузера и дополнительных сред выполнения.

## Запуск

Если старая версия запущена, выберите «Выход» в меню её значка в трее. Затем запустите Island.exe. Окно при запуске скрыто; значок находится возле часов, возможно в списке скрытых значков.

- **Ctrl + PgUp** — показать капсулу сверху по центру **экрана, на котором находится курсор мыши**. Для переноса на другой экран наведите туда мышь и снова нажмите сочетание, даже если остров уже открыт.
- Значки **изображения**, **заметки** и **шестерёнки** раскрывают соответствующий раздел. При наведении появляются подсказки.
- **Стрелка справа** сворачивает панель обратно в капсулу или раскрывает её.
- **Ctrl + PgDn**, **Esc** или 10 секунд без действий — скрыть весь остров.
- Пока поле заметки имеет фокус, автоскрытие приостановлено. Кнопка **Готово** возвращает обычное поведение.
- Нажатие значка в трее открывает остров; правая кнопка → **Выход** завершает приложение.

Автозапуска нет. Повторный запуск не создаёт второй экземпляр. Если сочетание клавиш занято, приложение сообщает об этом; остаётся доступ через трей. Палитра следует теме приложений Windows, поддерживается масштабирование DPI.

Капсула уменьшена с 440 × 54 до **200 × 42** логических пикселей, надпись Island убрана. Раскрытые панели сужены до 380 пикселей, шрифт сохранён. При масштабе Windows 125% и выше размеры в физических пикселях соответственно увеличиваются. Остров учитывает рабочую область и панель задач каждого монитора; раскрытие панели не меняет выбранный экран. При отключении монитора выбирается ближайший доступный.

## История изображений

Пока Island работает, он автоматически сохраняет изображения, которые **вновь попадают в буфер обмена Windows**. Это скриншоты через **Win + Shift + S**, Print Screen или картинки, скопированные из других программ. Уже находящееся в буфере изображение при запуске не импортируется — скопируйте его ещё раз.

- Хранятся **последние 5 изображений**. Шестое заменяет самое старое.
- Новый снимок **не открывает остров** и не перехватывает фокус.
- Одинаковые изображения в текущей пятёрке не дублируются. Копирование из самого Island также не добавляет дубль.
- Нажатие миниатюры выбирает снимок для предпросмотра.
- **Копировать** помещает полноразмерное изображение в буфер. Скрывайте остров через Ctrl + PgDn, затем вставляйте через Ctrl + V. Island старается вернуть фокус в предыдущее окно.
- **Сохранить PNG** позволяет выбрать файл вне истории. Он останется, даже когда снимок вытеснится из пятёрки.
- **Корзина** удаляет выбранный снимок из истории.

Поддерживаются растровые изображения, предоставляемые Windows как bitmap/DIB. Предел — 32 миллиона пикселей на изображение. Копирование пути, файла в Проводнике или ссылки на картинку не равно копированию изображения.

## Заметки

Откройте значок заметки и начните вводить текст — до **500 символов** с переносами строк. Изменения автоматически сохраняются примерно через 0,6 секунды после ввода, а также перед скрытием и обычным выходом из программы.

- **+ Новая** сохраняет текущую заметку и открывает пустое поле.
- Выбор заметки в списке открывает её для редактирования.
- **Готово** или **Ctrl + Enter** сохраняет текст и снимает фокус с поля.
- **Копировать текст** и **Удалить заметку** работают с открытой заметкой.

Заметки и история изображений остаются после перезапуска. Данные хранятся **локально** в `%LOCALAPPDATA%\Island`: изображения в папке `shots`, заметки в `notes.dat`. Сетевых запросов и синхронизации нет. Для полного удаления данных завершите Island и удалите эту папку.

## Громкость и таймер

Шестерёнка открывает прежние функции. Ползунок меняет громкость текущего устройства вывода; доступны колесо мыши и стрелки. Если звук отключён в Windows, Island показывает это и не снимает отключение автоматически.

Таймер принимает 0–999 минут и 0–59 секунд, поддерживает **паузу**, **продолжение** и **сброс**. Он работает при скрытом острове и подаёт короткий звук по завершении, не открывая окно. Слышимость зависит от громкости Windows. Просроченный за время сна таймер завершается после пробуждения; при выходе из программы таймер отменяется.

## Ресурсы и исходники

Скрытое приложение без работающего таймера ждёт событий Windows. Буфер отслеживается через уведомления, без постоянного опроса. Полноразмерное изображение обрабатывается при импорте или копировании; уменьшенные превью освобождаются при скрытии.

Исходники находятся в `source`. Нужен MinGW-w64 с GCC и windres. Выполните `source/build.ps1` из PowerShell: получится Island.exe. Библиотеки GCC включены в исполняемый файл, внешние зависимости — системные библиотеки Windows.

`source/test.ps1` запускает проверки в отдельной временной папке без подключения к пользовательскому буферу. Проверены ёмкость истории, дубликаты, PNG, конвертация bitmap, многострочные Unicode-заметки, редактирование и восстановление, автосохранение, автоскрытие, сворачивание, освобождение превью, таймер, удаление и защита повреждённого файла заметок. Отрисовка проверена на изображениях из кода интерфейса в светлой и тёмной теме. Реальная вставка в сторонние программы автоматически не проверялась.

Системные API: [буфер обмена](https://learn.microsoft.com/en-us/windows/win32/dataxchg/using-the-clipboard), [громкость](https://learn.microsoft.com/en-us/windows/win32/api/endpointvolume/nf-endpointvolume-iaudioendpointvolume-setmastervolumelevelscalar).
